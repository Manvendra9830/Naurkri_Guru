Role Summary

We are seeking a highly skilled Backend Engineer to join our dynamic team. In this role, you will design, build, and maintain scalable backend systems that power advanced AI solutions for large enterprises. This is an exciting opportunity to work at the intersection of backend development and cutting-edge AI technologies, contributing to high-performance systems that integrate machine learning models, databases, and cloud services. If you are passionate about backend engineering, enjoy solving complex problems, and thrive in a fast-paced environment, we want to hear from you.

Key Responsibilities

Develop Scalable Systems: Design and maintain backend systems for document retrieval, processing, and AI integration.
Create Python Libraries: Build robust Python libraries that leverage AWS services to support GenAI solutions.
Open Source Contributions: Contribute to and open-source internal tools to improve backend workflows.
API Development: Implement and optimize APIs for serving machine learning models, vector databases, and embeddings.
Model Integration: Build systems that integrate fine-tuned AI models with databases and other backend services.
Backend Architecture: Design high-performance backend architectures for AI training simulations.
Automation and Monitoring: Develop automated systems to monitor and optimize backend processes, addressing performance bottlenecks and resource allocation.
Performance Insights: Build tools to generate logs, metrics, and visualizations to monitor backend performance and improve efficiency.

Required Skills And Qualifications

Strong proficiency in Python and backend frameworks.
Solid understanding of data structures, algorithms, and system design.
Experience with cloud services (preferably AWS), including databases, networking, and storage.
Skilled in building APIs and working with containerization tools like Docker.
Familiarity with large-scale distributed systems.
Passionate about backend engineering best practices and writing clean, maintainable code.
Self-directed, independent, and comfortable in a fast-paced environment.
Professional-level English communication skills.
