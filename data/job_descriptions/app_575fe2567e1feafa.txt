Role Description
This is a full-time remote role for an Applied AI / Machine Learning Engineer focused on building intelligent orchestration systems for AI agents.
This role is centered around semantic routing, LLM workflows, AI agent orchestration, and structured execution pipelines rather than traditional AI model research.
You will work on designing systems that interpret fuzzy human intent, determine the correct tool execution paths, and orchestrate reliable multi-step AI workflows.
The ideal candidate understands how to build production-grade AI systems that balance latency, cost, reliability, and reasoning accuracy.
You will collaborate closely with backend and frontend engineering teams to develop scalable AI infrastructure powering enterprise automation workflows.


Key Responsibilities
Build semantic intent routing systems
Design AI agent orchestration workflows
Develop structured reasoning and execution pipelines
Implement LangGraph-based orchestration systems
Integrate lightweight open-source LLMs
Optimize AI latency, inference cost, and routing accuracy
Build tool selection and execution logic
Develop observability and evaluation pipelines for AI workflows
Create scalable backend services for AI orchestration


Qualifications
Strong Python programming skills
Experience with LLMs and AI agent frameworks
Familiarity with LangGraph, LangChain, or similar orchestration systems
Experience building production AI systems
Understanding of semantic search, embeddings, and vector databases
Familiarity with FastAPI or backend API development
Strong problem-solving and system design skills
Experience with cloud platforms such as AWS, GCP, or Azure
