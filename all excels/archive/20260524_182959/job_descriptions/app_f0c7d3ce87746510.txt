About PupilTree

PupilTree builds AI-driven education technology tools under the PupilSuite ecosystem. Among our offerings is a library of 60–65 Android games built in Unity, designed to make learning engaging for students. These games were developed by multiple teams over time, and while each game is functional and unique, there is currently no unified design language across the library, and some games have functional issues that need attention.

We are looking for a Unity developer who works in an AI-first development environment to bring consistency, quality, and scalable infrastructure to this game library.


Why This Timeline Works: AI-First Development

We understand that auditing 60–65 games, fixing bugs, and building a generation pipeline sounds aggressive for one month using traditional development methods. We are not looking for a traditional approach.

This role is designed for a developer who already works primarily through AI-powered tools — specifically Claude Code with MCP servers and connectors integrated into Unity workflows. The expectation is that repetitive tasks like UI component swaps, prefab standardization, font/style replacements, and common bug patterns across 65 similar educational games are handled at scale through AI-assisted automation, not one-by-one manual editing.

If your workflow still relies on manually opening each project, editing each scene, and testing each build individually — this contract is not the right fit. If you use AI agents to batch-process, audit, and modify Unity projects programmatically — we want to talk to you.


The Project

Phase 1 (Week 1) — Audit, Design System & Pilot Batch

- Audit all 60–65 games to catalog UI/UX inconsistencies, functional bugs, and overall quality
- Define and document a unified PupilTree design system: font styles, color schemes, button styles, navigation patterns, tutorial screen templates, loading/splash screens, and common UI components
- Apply the design system to a pilot batch of 5–10 games and fix any functional issues in those games
- Deliver the pilot batch for review — this establishes the quality benchmark for the remaining games

Phase 2 (Weeks 2–3) — Full Rollout & Bug Fixes

- Apply the design system across all remaining games using AI-assisted batch processing through Claude Code with MCP connectors
- Identify, diagnose, and fix functional issues across the library — including bugs, crashes, broken mechanics, and performance problems
- Ensure consistent user flows across all games — how players reach the game, how tutorials are presented, how menus and settings are structured
- Deliver production-ready builds for each updated and fixed game

Phase 3 (Week 4) — AI-Powered Game Generation Pipeline

- Design and build a reusable pipeline that uses AI agents (Claude Code with MCP) to generate new educational games based on the mechanics, patterns, and structures of the existing game library
- The pipeline should take a game idea or learning objective as input and produce a working Unity game prototype — leveraging the existing games as reference templates
- Document the pipeline thoroughly so the PupilTree team can operate and extend it independently
- The goal is to enable PupilTree to scale game production without building each game from scratch


What You'll Do

- Conduct a full audit of all 60–65 games to assess UI/UX inconsistencies, functional bugs, and overall quality
- Define and document a unified PupilTree design system and apply it across the entire library
- Modify UI elements to align with the new standard while retaining each game's unique visual identity and gameplay character

- Build an AI agent-powered pipeline for generating new Unity games based on ideas derived from existing games

- Deliver production-ready builds for each updated and fixed game, along with the functioning pipeline
